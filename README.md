# B-*Cat*
**B**uilding energy **B**enchmarking ***Cat***egories in South Korea
건축물대장 용도체계를 준용한 건물에너지 벤치마킹용 용도 카테고리

> **상태:** 최신본 `v2026.11.19` (`대표용도_매칭_261118.xlsx`) — 2026 신규 BM 용도 분류표(별표 1) 반영, 대분류 헤더코드(xxx000) 분리

---

## 1. 개요

- 건축물대장은 3수준 용도분류 체계를 가지며, 3수준 용도는 세움터에서 **"대표용도"**(`FLR_MAIN_PURPS_CD`)라는 이름으로 사용됩니다.
- 3수준 용도는 건축물대장 **층별개요(층용도)** 또는  전유부(용도)에 기재됩니다.
- 대표용도는 매우 세분화되어 있어 기후지역 × 용도 × 규모로 층화하면 그룹별 표본수가 극단적으로 적어집니다.
- B-Cat은 **용도적 유사성을 유지하면서 충분한 표본수를 확보**하도록 대표용도를 재구성한 **2수준 벤치마킹 용도 카테고리**입니다.

| 수준 | 컬럼 | 개수 (v2026.11.19) | 예시 |
|---|---|---|---|
| 입력: 세움터 층용도(대표용도) | `FLR_MAIN_PURPS_CD` | 722 | `09101` 종합병원 |
| BM 세부용도 (LV2) | `LV2_B_PURPS_CD2` | 289 (층용도 연결 284 + 미연결 5) | `BM09010` 종합병원 |
| BM 대분류 (LV0) | `LV0_B_PURPS_CD` | 35 (BM01–BM31, BMZ0·Z3·Z6·Z8·Z9) | `BM09` 의료시설 |

## 2. 적용 범위

| 구분 | 대장 대분류 코드 | BM 대분류 |
|---|---|---|
| **포함** | 01 단독주택 ~ 31 야영장시설 | 대장 대분류 번호와 동일한 `BMxx` |
| **포함** | 32 교정시설, 33 국방·군사시설 | `BM23` 교정및군사시설에 통합 |
| **포함** | 22 분뇨·쓰레기처리시설 | `BM30` 자원순환관련시설에 통합 (BM22 없음) |
| **포함** | Z5 문화및집회시설, Z7 축사·가축시설 | 각각 `BM05`, `BM21`로 통합 |
| **포함** | Z0, Z3, Z6, Z8, Z9 (구 용도코드) | `BMZx`로 유지 |

## 4. 컬럼 정의

| 컬럼 | 설명 | 형식 |
|---|---|---|
| `FLR_MAIN_PURPS_CD` | 세움터 층용도(대표용도) 코드 (층별개요/전유부) | 5자리 문자열, 예 `01001` |
| `FLR_MAIN_PURPS_CD_NM` | 층용도명 | |
| `LV2_B_PURPS_CD2` | BM 세부용도 **고유 코드** = `LV0_B_PURPS_CD` + `LV2_B_PURPS_CD` | 예 `BM01002` |
| `LV2_B_PURPS_CD` | 대분류 내 세부용도 일련번호 (대분류 간 중복됨) | 3자리, 예 `002` |
| `LV2_B_PURPS_CD_NM` | BM 세부용도명 | |
| `LV0_B_PURPS_CD` | BM 대분류 코드 | 예 `BM01`, `BMZ3` |
| `LV0_B_PURPS_CD_NM` | BM 대분류명 | |
| `ETC_YN` | 기타여부 (별표 1의 `○`) | `Y` / `N` |

- **조인 키는 반드시 `LV2_B_PURPS_CD2`를 사용**하십시오. `LV2_B_PURPS_CD`만으로는 대분류 간에 중복됩니다.
- 코드는 **문자열**로 읽어야 앞자리 0이 보존됩니다 (예: pandas `dtype=str`).

### 코드 부여 원칙 (v2026)

1. 같은 대분류 안에서 세부용도명이 기존과 같으면 **기존 번호 유지** (141개)
2. 이름만 바뀌고 소속 층용도코드가 그대로면 **기존 번호 유지, 명칭변경** (11개, 예: 고시원 → 다중생활시설)
3. 그 밖의 세부용도는 대분류 내 기존 최대 번호 다음부터 **신규 번호** (98개)
4. 폐지된 세부용도 번호(27개)는 **재사용하지 않음**
5. 층용도코드가 `000`으로 끝나는 **대분류 헤더코드**(예: `03000` 제1종근린생활시설)는 대분류 명칭일 뿐 세부용도가 아니므로, `기타○○` 세부용도에 연결하지 않고 대분류마다 **`○○(세부미상)` 세부용도를 신설해 1:1로 연결** (39개, 예: `03000` → `BM03032` 제1종근린생활시설(세부미상))
6. `기타○○` 세부용도는 세움터의 `기타○○` 세부코드(주로 `xx999`)에만 연결 (예: `BM03028` 기타근린생활시설 ↔ `03999` 기타제1종근린생활시설). 세움터에 해당 세부코드가 없는 `BM01004` 기타단독주택, `BM02003` 기타공동주택, `BM14005` 기타업무시설, `BM29001` 기타장례시설, `BMZ0001` 기타는 코드 사전에만 남기고 연결된 층용도코드는 없음

## 5. 사용법

아래는 가상의 5층 근린·업무 복합건물 1동에 B-Cat 용도를 부여하는 예시입니다.

### 1단계. 건축물대장 층별개요에서 층용도코드 확인

건축물대장(층별개요 또는 전유부)에서 층마다 **층용도코드**(`FLR_MAIN_PURPS_CD`, 세움터 대표용도)와 면적을 확인합니다.

| 층 | 층용도코드 | 층용도명 | 면적(㎡) |
|---|---|---|---|
| 1층 | `03001` | 소매점 | 120 |
| 2층 | `04001` | 일반음식점 | 150 |
| 3층 | `14204` | 사무소 | 200 |
| 4층 | `14204` | 사무소 | 200 |
| 5층 | `14204` | 사무소 | 200 |

> 코드는 반드시 **5자리 문자**로 다룹니다. 엑셀에서 숫자로 열면 `03001`이 `3001`로 바뀌므로 셀 서식을 '텍스트'로 지정하십시오.

### 2단계. 매칭표에서 층용도코드 찾기

`대표용도_매칭_261118.xlsx`의 `1 BM용도분류표+대표용도` 시트(또는 `대표용도_매칭_261118.csv`)에서 `FLR_MAIN_PURPS_CD` 열로 코드를 찾습니다.

| 층용도코드 | 층용도명 | BM 세부용도 (`LV2_B_PURPS_CD2`) | BM 대분류 (`LV0_B_PURPS_CD`) |
|---|---|---|---|
| `03001` | 소매점 | `BM03001` 상점 | `BM03` 제1종근생 |
| `04001` | 일반음식점 | `BM04001` 음식점 | `BM04` 제2종근생 |
| `14204` | 사무소 | `BM14004` 일반업무시설 | `BM14` 업무시설 |

### 3단계. 층별 BM 용도를 건물 단위로 합산

층별 면적을 BM 세부용도별로 더합니다.

| BM 세부용도 | 합계 면적(㎡) | 비율 |
|---|---|---|
| `BM14004` 일반업무시설 | 600 | 69% |
| `BM04001` 음식점 | 150 | 17% |
| `BM03001` 상점 | 120 | 14% |

### 4단계. 건물의 대표 BM 용도 결정

복합용도 건물은 사용자가 정한 규칙으로 대표 용도를 하나 정합니다. 예를 들어 '연면적 최대 용도' 규칙을 쓰면 이 건물은 다음과 같습니다.

- 건물 BM 세부용도: **`BM14004` 일반업무시설**
- 건물 BM 대분류: **`BM14` 업무시설**

### 5단계. 같은 BM 용도끼리 묶어 벤치마킹

같은 `LV2_B_PURPS_CD2`(예: `BM14004`)를 가진 건물끼리 묶은 뒤, 필요에 따라 기후지역·규모로 다시 나누어 에너지 사용량(원단위)을 비교합니다. 그룹의 표본수가 너무 적으면 한 단계 위인 BM 대분류(`BM14`)로 묶어 비교합니다.

> 묶을 때는 이름이 아니라 **코드**(`LV2_B_PURPS_CD2`)를 사용하십시오. 같은 이름의 세부용도가 여러 대분류에 있을 수 있습니다(예: `일반업무시설`은 `BM03027`, `BM04012`, `BM14004`, `BMZ3026`).

### 참고 예 0. 대분류만 기재된 경우

층용도코드가 `03000`(제1종근린생활시설)처럼 `000`으로 끝나면 세부용도를 알 수 없는 경우입니다. 이 코드는 `BM03032` 제1종근린생활시설(세부미상)로 분류되며, `03999` 기타제1종근린생활시설(`BM03028` 기타근린생활시설)과는 구분됩니다.

### 참고 예 1. 같은 시설이 여러 코드로 등록된 경우

교도소는 세움터에 옛 코드와 새 코드가 함께 있지만 같은 BM 세부용도로 분류됩니다.

| 층용도코드 | 층용도명 | BM 세부용도 |
|---|---|---|
| `23203` | 교도소(23) | `BM23005` 교정시설 |
| `32103` | 교도소(32) | `BM23005` 교정시설 |

### 참고 예 2. 이전 버전(240123) 결과와 비교하는 경우

`변경대응표_240123_261118.csv`에서 층용도코드를 찾아 이전 코드와 새 코드를 대응시킵니다.

| 층용도코드 | 층용도명 | 240123 | 2026 | 변경유형 |
|---|---|---|---|---|
| `04029` | 고시원 | `BM04015` 고시원 | `BM04015` 다중생활시설 | 명칭변경 (코드 동일) |
| `13110` | 골프장 | `BM13009` 골프장 | `BM13001` 생활체육시설 | 재배정 (코드 변경) |
| `18003` | 물류터미널 | (없음) | `BM18003` 물류하역시설 | 신규코드 |

- **명칭변경**: 코드가 같으므로 이전 결과를 그대로 이어서 쓸 수 있습니다.
- **재배정**: 코드가 바뀌었으므로 이전 결과는 새 코드로 다시 묶어야 합니다.
- **신규코드**: 이전 버전에는 매칭 결과가 없던 용도입니다.

세부용도 단위로 보려면 `세부용도대응표_240123_261118.csv`를 사용합니다. 예를 들어 240123의 `BM13009` 골프장(폐지)은 층용도코드 1개(`13110` 골프장)가 `BM13001` 생활체육시설로 옮겨졌음을 확인할 수 있습니다.

## 8. 주의사항 및 향후 과제

- 본 분류는 **건물에너지 벤치마킹용 용도 카테고리**이며, 의견 수렴에 따라 수정·변경·병합될 수 있습니다.
- 세부용도별 표본수와 에너지 사용 특성의 유사성에 대한 정량 검증 결과는 추후 공개 예정입니다.
- 데이터 기반(data-driven) 신규 분류 카테고리 연구가 필요합니다.
- 의견 및 오류 제보: GitHub **Issues**를 이용해 주십시오.
