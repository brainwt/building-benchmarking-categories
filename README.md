# B-*Cat*
**B**uilding energy **B**enchmarking ***Cat***egories in South Korea
건축물대장의 용도를 건물 에너지 사용량 비교(벤치마킹)에 맞게 묶은 용도 분류표

> **현재 버전:** `v2026.11.19` (`대표용도_매칭_261118.xlsx`)
> 2026년 새 BM 용도 분류표(별표 1)를 반영했고, 대분류만 적힌 코드(`xxx000`)를 따로 분리했습니다.



## 1. 개요

- 건축물대장에는 층마다 **층용도코드**(`FLR_MAIN_PURPS_CD`)가 적혀 있습니다. 세움터에서는 이를 "대표용도"라고 부릅니다.
- 층용도코드는 건축물대장의 **층별개요**(층용도)나 **전유부**(용도)에서 확인할 수 있습니다.
- 층용도코드는 종류가 너무 많습니다. 그래서 지역·용도·규모로 건물을 나누면 그룹마다 건물 수가 너무 적어져 비교하기 어렵습니다.
- B-Cat은 비슷한 용도끼리 묶어 **그룹마다 비교할 만큼의 건물 수를 확보**하도록 만든 **2단계 용도 분류**입니다.

| 단계 | 컬럼 | 개수 (v2026.11.19) | 예시 |
|---|---|---|---|
| 입력: 층용도코드 | `FLR_MAIN_PURPS_CD` | 722 | `09101` 종합병원 |
| BM 세부용도 | `LV2_B_PURPS_CD2` | 289 (층용도코드가 연결된 것 284 + 연결 없는 것 5) | `BM09010` 종합병원 |
| BM 대분류 | `LV0_B_PURPS_CD` | 35 (BM01~BM31, BMZ0·Z3·Z6·Z8·Z9) | `BM09` 의료시설 |



## 2. 다루는 범위

| 건축물대장 대분류 | BM 대분류 |
|---|---|
| 01 단독주택 ~ 31 야영장시설 | 대장 대분류와 같은 번호 `BMxx` |
| 32 교정시설, 33 국방·군사시설 | `BM23` 교정및군사시설로 합침 |
| 22 분뇨·쓰레기처리시설 | `BM30` 자원순환관련시설로 합침 (`BM22`는 없음) |
| Z5 문화및집회시설, Z7 축사·가축시설 | 각각 `BM05`, `BM21`로 합침 |
| Z0, Z3, Z6, Z8, Z9 (옛 용도코드) | `BMZx`로 그대로 둠 |

## 4. 컬럼 설명

| 컬럼 | 설명 | 형식 |
|---|---|---|
| `FLR_MAIN_PURPS_CD` | 층용도코드 (층별개요·전유부) | 5자리 문자, 예 `01001` |
| `FLR_MAIN_PURPS_CD_NM` | 층용도명 | |
| `LV2_B_PURPS_CD2` | BM 세부용도 **코드** (대분류 코드 + 일련번호) | 예 `BM01002` |
| `LV2_B_PURPS_CD` | 대분류 안에서의 일련번호 (다른 대분류와 겹칠 수 있음) | 3자리, 예 `002` |
| `LV2_B_PURPS_CD_NM` | BM 세부용도 이름 | |
| `LV0_B_PURPS_CD` | BM 대분류 코드 | 예 `BM01`, `BMZ3` |
| `LV0_B_PURPS_CD_NM` | BM 대분류 이름 | |
| `ETC_YN` | '기타' 용도 여부 (별표 1의 `○` 표시) | `Y` / `N` |

- 세부용도를 연결하거나 묶을 때는 **`LV2_B_PURPS_CD2`를 쓰십시오.** `LV2_B_PURPS_CD`(3자리)는 대분류가 달라도 같은 번호가 나옵니다.
- 코드는 **문자**로 읽어야 앞의 0이 지워지지 않습니다 (예: pandas `dtype=str`).
- 세부용도 이름도 겹칠 수 있으니 이름보다 코드로 묶으십시오. 예를 들어 `일반업무시설`은 `BM03027`, `BM04012`, `BM14004`, `BMZ3026` 네 개가 있습니다.

#### 코드를 매긴 규칙 (v2026)

1. 같은 대분류 안에서 세부용도 이름이 예전과 같으면 **예전 번호를 그대로** 씁니다. (141개)
2. 이름만 바뀌고 묶인 층용도코드가 같으면 **예전 번호를 쓰고 이름만 바꿉니다.** (11개, 예: 고시원 → 다중생활시설)
3. 나머지 세부용도는 대분류 안의 마지막 번호 다음부터 **새 번호**를 붙입니다. (98개)
4. 없어진 세부용도의 번호(27개)는 **다시 쓰지 않습니다.**
5. `000`으로 끝나는 층용도코드(예: `03000` 제1종근린생활시설)는 대분류 이름만 적힌 코드입니다. 그래서 '기타' 세부용도에 넣지 않고, 대분류마다 **`○○(세부미상)` 세부용도를 따로 만들어 하나씩 연결**했습니다. (39개, 예: `03000` → `BM03032` 제1종근린생활시설(세부미상))
6. '기타' 세부용도에는 세움터의 '기타' 층용도코드(주로 `xx999`)만 연결합니다. (예: `03999` 기타제1종근린생활시설 → `BM03028` 기타근린생활시설)
   세움터에 맞는 '기타' 코드가 없는 5개(`BM01004` 기타단독주택, `BM02003` 기타공동주택, `BM14005` 기타업무시설, `BM29001` 기타장례시설, `BMZ0001` 기타)는 목록에만 남겨 두었고, 연결된 층용도코드가 없습니다.



## 5. 사용법

5층짜리 상가·사무실 건물 1동(가상)에 B-Cat 용도를 붙이는 예입니다.

#### 1단계. 건축물대장에서 층용도코드 확인

건축물대장(층별개요 또는 전유부)에서 층마다 **층용도코드**와 면적을 확인합니다.

| 층 | 층용도코드 | 층용도명 | 면적(㎡) |
|---|---|---|---|
| 1층 | `03001` | 소매점 | 120 |
| 2층 | `04001` | 일반음식점 | 150 |
| 3층 | `14204` | 사무소 | 200 |
| 4층 | `14204` | 사무소 | 200 |
| 5층 | `14204` | 사무소 | 200 |

> 코드는 꼭 **5자리 문자**로 다루십시오. 엑셀에서 숫자로 열면 `03001`이 `3001`로 바뀝니다. 셀 서식을 '텍스트'로 바꿔 두십시오.

#### 2단계. 매칭표에서 층용도코드 찾기

`대표용도_매칭_261118.xlsx`의 `1 BM용도분류표+대표용도` 시트(또는 `대표용도_매칭_261118.csv`)에서 `FLR_MAIN_PURPS_CD` 열로 코드를 찾습니다.

| 층용도코드 | 층용도명 | BM 세부용도 (`LV2_B_PURPS_CD2`) | BM 대분류 (`LV0_B_PURPS_CD`) |
|---|---|---|---|
| `03001` | 소매점 | `BM03001` 상점 | `BM03` 제1종근생 |
| `04001` | 일반음식점 | `BM04001` 음식점 | `BM04` 제2종근생 |
| `14204` | 사무소 | `BM14004` 일반업무시설 | `BM14` 업무시설 |

#### 3단계. 층별 결과를 건물 전체로 합치기

1·2단계 결과를 한 표에 모은 뒤, 같은 BM 세부용도끼리 면적을 더합니다.

| 층 | 층용도코드 | 층용도명 | 면적(㎡) | BM 세부용도 | BM 대분류 |
|---|---|---|---|---|---|
| 1층 | `03001` | 소매점 | 120 | `BM03001` 상점 | `BM03` 제1종근생 |
| 2층 | `04001` | 일반음식점 | 150 | `BM04001` 음식점 | `BM04` 제2종근생 |
| 3층 | `14204` | 사무소 | 200 | `BM14004` 일반업무시설 | `BM14` 업무시설 |
| 4층 | `14204` | 사무소 | 200 | `BM14004` 일반업무시설 | `BM14` 업무시설 |
| 5층 | `14204` | 사무소 | 200 | `BM14004` 일반업무시설 | `BM14` 업무시설 |
| **합계** | | | **870** | `BM14004` 600㎡ (69%) · `BM04001` 150㎡ (17%) · `BM03001` 120㎡ (14%) | |

#### 4단계. 건물의 대표 용도 정하기

여러 용도가 섞인 건물은 정해 둔 규칙에 따라 대표 용도를 하나 고릅니다. 예를 들어 '면적이 가장 큰 용도'로 정하면 이 건물은 다음과 같습니다.

- 건물 BM 세부용도: **`BM14004` 일반업무시설**
- 건물 BM 대분류: **`BM14` 업무시설**


## 6. 주의사항
#### 대분류만 적혀 있는 경우

층용도코드가 `03000`(제1종근린생활시설)처럼 `000`으로 끝나면 세부 용도를 알 수 없는 경우입니다. 이 코드는 `BM03032` 제1종근린생활시설(세부미상)로 분류합니다. `03999` 기타제1종근린생활시설(`BM03028` 기타근린생활시설)과는 다른 것입니다.

#### 같은 시설이 여러 코드로 있는 경우

교도소는 세움터에 옛 코드와 새 코드가 함께 있습니다. 어느 코드든 같은 BM 세부용도로 분류됩니다.

| 층용도코드 | 층용도명 | BM 세부용도 |
|---|---|---|
| `23203` | 교도소(23) | `BM23005` 교정시설 |
| `32103` | 교도소(32) | `BM23005` 교정시설 |

#### 이전 버전(240123) 결과와 비교하는 경우

`변경대응표_240123_261118.csv`에서 층용도코드를 찾으면 이전 분류와 지금 분류를 나란히 볼 수 있습니다.

| 층용도코드 | 층용도명 | 이전 (240123) | 지금 (2026) | 변경 구분 |
|---|---|---|---|---|
| `04029` | 고시원 | `BM04015` 고시원 | `BM04015` 다중생활시설 | 명칭변경 (코드 같음) |
| `13110` | 골프장 | `BM13009` 골프장 | `BM13001` 생활체육시설 | 재배정 (코드 바뀜) |
| `18003` | 물류터미널 | (없음) | `BM18003` 물류하역시설 | 신규코드 |

- **명칭변경**: 코드가 같으니 이전 결과를 그대로 이어서 쓸 수 있습니다.
- **재배정**: 코드가 바뀌었으니 이전 결과를 새 코드로 다시 묶어야 합니다.
- **신규코드**: 이전 버전에는 없던 용도입니다.

세부용도 단위로 보려면 `세부용도대응표_240123_261118.csv`를 쓰십시오. 예를 들어 이전의 `BM13009` 골프장(없어짐)은 층용도코드 1개(`13110` 골프장)가 `BM13001` 생활체육시설로 옮겨진 것을 확인할 수 있습니다.
